# Replaceable Site Images

Swap any SVG here with a JPG, PNG, WebP, GIF, MP4 poster, or your own SVG, then update the matching `src` in the HTML if the filename changes.

- `home-*.svg`: home carousel cards.
- `about-*.svg`: Behind the pixels postcard images.
- `about-amina-photo.jpeg` and `about-sand-ami.jpeg`: Current Behind the pixels replacement photos.
- `about-beach-photo.jpeg`, `about-cafe-photo.jpeg`, `about-college-photo.png`, and `about-craft-photo.png`: Additional Behind the pixels replacement photos.
- `skill-*.svg`: I’ve got your back card-stack images.
- `work-*.svg`: Works page project card images.
- `garden-photo-*.svg` and `garden-video-*.svg`: Garden page media boxes.
- `garden-photo-6.svg`: Extra Garden collage media box added in place of the vector slot.
- `flower-pot.svg`: Garden hero and flower interaction box vector.
- `heart-link.svg`: More-to-come and digital-home section icon.
- `gallery-mark.svg`: Digital-home gallery section icon.
- `camera-mark.svg`: Digital-home camera section icon.
- `digital-home-vector.svg`: Current home digital-home section icon from the supplied SVG.
- `garden-hero-vector.svg`: Current Garden hero icon from the supplied Adobe Express SVG.

Project card Behance links live in `works.html` on each `.project-card` anchor.
